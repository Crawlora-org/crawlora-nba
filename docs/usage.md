# NBA API endpoint reference and client usage

This reference lists all 70 public NBA API endpoints exposed by the JavaScript/TypeScript, Python, Go, Ruby, Java, PHP, and Rust clients, including the `@crawlora-org/nba`, `crawlora-nba`, and `crawlora-nba` packages. The clients call Crawlora's hosted API. Set `CRAWLORA_API_KEY` to a key for your Crawlora account before making requests. Service usage is billed under that account. These clients do not run a browser or scrape NBA locally; Crawlora is independent from and not endorsed by NBA or its owners.

The package tracks the public API contract revision `sha256:343b4e2ca3bea9fd723ed7fa4522b82cbfcf68cc70aec065ce0692310568d3e9` bundled with release `0.1.0`. Maintainers can preview daily contract updates with the repository's `Sync live API contract` workflow; unchanged contracts do not produce package releases.

All language packages expose the selected public API operations in the bundled contract. JavaScript uses camelCase methods, Python and Rust use snake_case methods. JavaScript, Python, and Rust methods are grouped under `nba`; Rust uses typed parameter structs and returns the complete HTTP response.

## Client forms

- JavaScript: import `NBAClient` (also exported as `Client`) from `@crawlora-org/nba`; use `new NBAClient({ apiKey })` and `await client.method({ ... })`.
- Python: import `NBAClient` (also exported as `Client`) from `crawlora_nba`; use `with NBAClient(api_key=...) as client` and `client.method(...)`.
- Python async class: `AsyncNBAClient`, used with `async with` and `await`.
- Rust: add `crawlora-nba` with Cargo; import `Client` and the generated operation parameter struct, then call `client.nba.<snake_case_method>(params).await`. See the [Rust example](https://github.com/Crawlora-org/crawlora-nba/blob/main/rust/examples/quick_start.rs).

See the package READMEs for installation details. Keep API keys in environment variables or a secret store; do not commit them.
